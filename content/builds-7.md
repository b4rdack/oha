Сортировка и своевременная утилизация калибровочных чертежей неотъемлемая часть игрового процесса.  

## 1️⃣ Хранение чертежей
Идеальное место для хранения большого количества хороших или пригодных для утилизации чертежей - Вечная земля.  

🔰 **Стройте сооружения, ставьте столы и ящики для хранения, чтобы поместить в них все чертежи.**  

Идеально выделить по ящику для каждого вида оружия и его стилю.  

![[guides/my-storage.webp]]  

## 2️⃣ Рекомендации по утилизации чертежей
⭐ Смело можно уничтожать чертежи с показателями "Устойчивость" для любого вида оружия.  
⭐ Пока в игре нет необходимости создавать холодное оружие - оставьте себе на хранение несколько чертежей с показателями "Критический урон" и "Шанс критического попадания". Остальные - смело уничтожайте.  
⭐ Обращайте внимание на значение показателей характеристик. Если показатель близок к минимальному значению - уничтожайте, если у Вас уже есть 2-3 похожих чертежа.  
⭐ Для пистолета, пистолета-пулемёта, штурмовых винтовок и пулемётов крайне редко используются чертежи с показателями характеристик "Урон по уязвимостям" и "Критический урон".  
⭐ Для дробовика не используется показатель характеристики "Урон по уязвимостям".  

## 3️⃣ Заключение
Рекомендации не должны привести вас к отсутствию чертежей в запасе - всегда держите у себя на хранении несколько чертежи с различными показателями характеристик.  

🔰 Чтобы **меньше** уходило **времени на разбор - уничтожайте чертежи заранее**, что может не пригодиться, исходя из рекомендаций и из имеющихся чертежей в запасе.
